Tài liệu Kỹ thuật & Ôn tập bảo vệ: Tích hợp AI Gemini

Phân công phụ trách: Nguyễn Hưng | Dự án: Tủ Sách Cá Nhân (ver06 nâng cấp AI)

1. Kiến thức JavaScript cốt lõi Nguyễn Hưng cần nắm vững

Cú pháp / Hàm Bản chất lý thuyết Ứng dụng thực tế trong bài của Hưng
async / await Cú pháp xử lý bất đồng bộ giúp code chạy tuần tự từ trên xuống dưới khi phải chờ mạng Internet trả dữ liệu về. Chờ Gemini suy nghĩ xong câu trả lời rồi mới lấy văn bản đó chuyển tiếp sang cho hàm emailjs.send().
fetch(url, options) Hàm có sẵn của trình duyệt dùng để gửi yêu cầu HTTP (GET hoặc POST) tới máy chủ từ xa. Dùng GET để lấy danh sách mô hình AI khả dụng và dùng POST để gửi câu hỏi lên máy chủ Google Gemini.
response.json() Chuyển đổi luồng dữ liệu thô từ máy chủ trả về thành đối tượng JavaScript (Object) để truy xuất thuộc tính. Đọc danh sách data.models hoặc lấy câu trả lời tại data.candidates[0].content.parts[0].text.
JSON.stringify(obj) & JSON.parse(str) Biến Object thành chuỗi văn bản (để gửi qua mạng hoặc lưu vào LocalStorage) và ngược lại. Lưu cấu hình AI (aiConfig gồm Key, Model, Temperature) vào localStorage và đóng gói requestBody gửi cho AI.
try { ... } catch (err) { ... } Khối lệnh bắt ngoại lệ. Nếu lệnh trong try gặp lỗi (mất mạng, sai API Key), chương trình nhảy xuống catch chứ không bị đơ trang. Bắt lỗi mã 400 (sai Key), mã 500 (mất mạng) và hiển thị lên thanh trạng thái hienThiThongBaoNgoaiLeHTML().
Array.filter() & Array.forEach() Duyệt qua mảng dữ liệu để lọc ra các phần tử thỏa điều kiện hoặc thực thi hành động lặp. Lọc ra các mô hình có hỗ trợ generateContent và tạo thẻ <option> đưa vào ô chọn Model.

2. Giải thích chi tiết từng dòng code trong assets/js/gemini-service.js

Hàm 1: fetchAvailableModels(apiKey) — Lấy danh sách mô hình từ Google
async function fetchAvailableModels(apiKey) { const url = `https://generativelanguage.googleapis.com/v1beta/models?key=${apiKey}`; const response = await fetch(url); const data = await response.json(); if (!response.ok) { throw new Error(data.error?.message || 'Không thể lấy danh sách mô hình'); } return data.models.filter(m => m.supportedGenerationMethods && m.supportedGenerationMethods.includes('generateContent') ); }
  • Dòng 1: Khai báo hàm bất đồng bộ async nhận đầu vào là chuỗi apiKey người dùng nhập.
  • Dòng 2: Ghép khóa API vào đường dẫn chuẩn của Google Gemini để truy vấn danh sách model.
  • Dòng 3-4: Gửi yêu cầu GET qua mạng và giải mã kết quả trả về sang dạng JSON.
  • Dòng 5-7: Kiểm tra thuộc tính response.ok (mã HTTP 200-299). Nếu khóa sai, ném lỗi ra ngoài để giao diện bắt được.
  • Dòng 8-11: Lọc danh sách mô hình, chỉ giữ lại những mô hình có phương thức generateContent (sinh văn bản trò chuyện).
Hàm 2: callGeminiAPI(promptText, systemInstruction) — Hàm lõi gửi yêu cầu sinh văn bản
async function callGeminiAPI(promptText, systemInstruction = '') { const config = getAIConfig(); if (!config.apiKey) throw new Error('Chưa cấu hình Gemini API Key trong trang Tùy chỉnh.'); const modelName = config.model || 'models/gemini-1.5-flash'; const url = `https://generativelanguage.googleapis.com/v1beta/${modelName}:generateContent?key=${config.apiKey}`; const requestBody = { contents: [{ parts: [{ text: promptText }] }], generationConfig: { temperature: parseFloat(config.temperature ?? 0.7), maxOutputTokens: parseInt(config.maxTokens ?? 800, 10) } }; if (systemInstruction || config.systemPrompt) { requestBody.systemInstruction = { parts: [{ text: systemInstruction || config.systemPrompt }] }; } const response = await fetch(url, { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify(requestBody) }); const data = await response.json(); if (!response.ok) throw new Error(data.error?.message || 'Lỗi gọi API Gemini'); return data.candidates?.[0]?.content?.parts?.[0]?.text || 'Không có phản hồi từ AI.'; }
  • getAIConfig(): Đọc cấu hình từ localStorage.getItem('aiConfig').
  • generationConfig: Truyền các thông số điều chỉnh AI gồm temperature (độ sáng tạo từ 0.0 đến 1.0) và maxOutputTokens (độ dài câu trả lời tối đa).
  • method: 'POST': Gửi dữ liệu dạng JSON lên máy chủ Google và trích xuất văn bản trả về ở nhánh candidates[0].content.parts[0].text.
Hàm 3: Kết hợp AI + EmailJS khi bấm nút "Ghi chú AI & Gửi Mail" trên thẻ sách
async function sendBookAINoteEmail(bookId) { const book = getBooks().find(b => String(b.id) === String(bookId)); const noteText = await generateBookNote(book); emailjs.init(emailConfig.publicKey); await emailjs.send(emailConfig.serviceId, emailConfig.templateId, { to_email: emailConfig.targetEmail, book_title: book.title, ai_generated_note: noteText, message: noteText, time: new Date().toLocaleString('vi-VN') }); }
  • Bước 1: Tìm thông tin cuốn sách theo bookId từ bộ nhớ trình duyệt.
  • Bước 2: Chờ hàm await generateBookNote(book) gọi Gemini tạo bản tóm tắt và bài học rút ra.
  • Bước 3: Truyền kết quả văn bản vừa nhận được vào cả 2 biến ai_generated_note và message của emailjs.send() để tương thích với mọi mẫu Email Template trên Dashboard EmailJS.
Hàm 4: Xử lý lệnh thông minh trong khung Chat góc màn hình (Đổi giao diện, gợi ý sách, gửi mail)
Khi người dùng chat ở khung góc phải, hàm handleChatCommand(userText) sẽ đính kèm toàn bộ danh sách sách hiện có trong getBooks() vào lời nhắc cho AI, đồng thời yêu cầu AI trả về kèm mã lệnh điều khiển nếu người dùng muốn thực hiện thao tác:
  • Nếu người dùng nói "Mình đang buồn/mỏi mắt, đổi giao diện tối giúp mình" $\rightarrow$ AI trả về thẻ lệnh [THEME:cyborg] $\rightarrow$ Code JS tự động gọi applyTheme('cyborg') đổi màu trang web ngay lập tức.
  • Nếu người dùng nói "Viết email tổng hợp sách đang đọc và gửi đi giúp mình" $\rightarrow$ AI soạn nội dung trong thẻ [SEND_EMAIL:nội dung...] $\rightarrow$ Code JS tự động kích hoạt emailjs.send() gửi thư ngầm và báo thành công ngay trong khung chat.
