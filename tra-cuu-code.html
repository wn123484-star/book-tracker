2. Giải Thích Chi Tiết Cú Pháp HTML / CSS / JS (Dành Cho Người Mới Học) ⬆ Quay lại Bảng tra cứu

2.1. Vì sao trong CSS và JS lúc dùng dấu #, lúc dùng dấu ., lúc dùng [...]?

⬆ Bảng tra cứu
  • Dấu thăng # (Chọn theo id - Duy nhất): Trong HTML, mỗi phần tử quan trọng chỉ có 1 mã id duy nhất (giống như số căn cước công dân). Ví dụ: <div id="bookGrid">. Khi viết CSS hoặc tìm trong JS, ta dùng #bookGrid để chỉ đích danh khung kệ sách đó.
  • Dấu chấm . (Chọn theo class - Nhóm nhiều phần tử): Nhiều thẻ HTML có thể dùng chung 1 class để có cùng kiểu trang trí (giống như mặc đồng phục). Ví dụ: 12 cuốn sách đều có class="book-card". Trong CSS viết .book-card { border-radius: 16px; } thì cả 12 thẻ sách đều được bo tròn góc.
  • Dấu ngoặc vuông [thuộc_tính] (Chọn theo thuộc tính tùy chỉnh): Ví dụ html[data-font="priority-bold"] nghĩa là: "Khi thẻ <html> đang mang thuộc tính data-font có giá trị là priority-bold thì áp dụng font chữ đậm".
  • Dấu hai chấm :root, :hover:
    • :root là gốc của trang web (thẻ <html>), dùng để đặt biến dùng chung như --app-font-family.
    • :hover là hiệu ứng khi người dùng rê con trỏ chuột lên nút bấm hoặc thẻ sách.

2.2. Vì sao trong JavaScript lúc dùng const, lúc dùng let, lúc dùng function?

⬆ Bảng tra cứu
  • Từ khóa const (Hằng số / Tham chiếu cố định): Dùng khi biến đó chỉ gắn vào 1 phần tử cố định và không bao giờ gán lại bằng thứ khác. Ví dụ: const bookGrid = document.getElementById('bookGrid'); (Khung kệ sách luôn là khung đó suốt quá trình chạy).
  • Từ khóa let (Biến có thể thay đổi giá trị): Dùng khi giá trị bên trong cần cộng thêm hoặc thay đổi liên tục. Ví dụ ở Trang chủ: let readCount = 0; sau đó mỗi lần gặp sách đã đọc thì tăng lên 1 (readCount++). Nếu dùng const ở đây thì trình duyệt sẽ báo lỗi ngay vì const không cho phép cộng thêm!
  • Hàm function tenHam(thamSo) { ... } và Hàm mũi tên (thamSo) => { ... }:
    • Cả hai đều là gom một nhóm câu lệnh lại để tái sử dụng nhiều lần.
    • function getBooks() {...} là cách viết truyền thống, dễ gọi ở bất cứ đâu.
    • books.forEach(b => { ... }) là hàm mũi tên (Arrow Function trong chuẩn ES6+), giúp viết ngắn gọn khi truyền hàm vào trong các thao tác duyệt mảng hoặc bắt sự kiện click chuột.

2.3. Các hàm xử lý mảng trong JavaScript (forEach, filter, sort, map, find) làm gì?

⬆ Bảng tra cứu
  • .forEach(b => ...) (Duyệt qua từng phần tử): Giống như đi điểm danh từng cuốn sách từ đầu kệ đến cuối kệ để đếm số lượng.
  • .filter(b => điều_kiện) (Lọc danh sách): Tạo ra một danh sách mới chỉ giữ lại những cuốn sách trả về kết quả true (Đúng). Dùng trong hàm getFilteredAndSortedBooks() để lọc theo từ khóa, trạng thái và mức độ ưu tiên.
  • .sort((a, b) => ...) (Sắp xếp thứ tự): Đổi chỗ 2 cuốn sách a và b dựa trên hiệu số ngày hạn đọc (new Date(a.deadline) - new Date(b.deadline)) để xếp cuốn nào cần đọc gấp lên trước.
  • .map(book => `...HTML...`).join('') (Biến dữ liệu thành giao diện): Biến mỗi đối tượng sách trong mảng thành một đoạn mã HTML thẻ sách (Card), sau đó .join('') nối tất cả lại thành 1 chuỗi HTML dài để đổ vào bookGrid.innerHTML.
  • .find(b => b.id === id) & .findIndex(...): Tìm đúng cuốn sách (hoặc vị trí cuốn sách) có mã ID trùng với nút Sửa/Xóa mà người dùng vừa bấm.

2.4. Cú pháp HTML & Giao tiếp trình duyệt (localStorage, JSON, try...catch)

⬆ Bảng tra cứu
  • Tại sao phải dùng JSON.stringify() và JSON.parse() khi lưu vào localStorage? Vì bộ nhớ localStorage của trình duyệt chỉ biết lưu chữ văn bản (String), không lưu trực tiếp được mảng đối tượng JavaScript. Do đó:
    • Khi lưu: Phải dùng JSON.stringify(booksArray) để biến mảng sách thành chuỗi văn bản.
    • Khi đọc lên: Phải dùng JSON.parse(rawData) để biến chuỗi văn bản ngược lại thành mảng sách.
  • Tại sao dùng try { ... } catch (e) { ... }? Để "bọc lót" các đoạn code có nguy cơ gây lỗi (như đọc tệp JSON người dùng tải lên bị sai cú pháp, hoặc bộ nhớ trình duyệt bị đầy). Nếu có lỗi xảy ra trong khối try, chương trình không bị đơ mà nhảy xuống khối catch để hiện thông báo màu đỏ lên khung #systemStatusBox.
  • Thuộc tính data-* (Ví dụ data-icon="logo.png", data-test-code="200"): Là chuẩn HTML5 cho phép ta gắn thêm thông tin phụ vào thẻ HTML để JavaScript đọc lên bằng getAttribute('data-icon').

[GD-01, DL-02, DL-03, DL-04, CD-01] Cơ chế đổi Giao diện, Font chữ & Bộ biểu tượng

⬆ Bảng tra cứu
  • Vì sao phải đặt đoạn script (function(){...})() ngay trong thẻ <head> (GD-01)? Trình duyệt đọc file HTML từ trên xuống dưới. Nếu đợi tải xong hết trang mới đổi màu giao diện thì màn hình sẽ bị chớp trắng 1 giây.
